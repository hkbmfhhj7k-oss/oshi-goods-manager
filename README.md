# 推し活グッズ管理

スマホ前提の、端末内保存型グッズ管理Webアプリです。

## GitHub Pagesで公開する手順

1. GitHubで新しいリポジトリを作成
2. このフォルダ内のファイルをすべてアップロード
3. GitHubのリポジトリで `Settings` を開く
4. `Pages` を開く
5. `Build and deployment` の `Source` を `Deploy from a branch` にする
6. Branch を `main`、Folder を `/(root)` にして保存
7. 数分後に表示されるPages URLをSafariで開く
8. iPhoneの共有メニューから「ホーム画面に追加」

通常のURL形式：
`https://<GitHubユーザー名>.github.io/<リポジトリ名>/`

## データ保存について

商品データ・購入履歴・所持情報はブラウザの `localStorage` に保存します。

そのため、

- GitHubには商品データは保存されません
- 外部サーバーへ購入情報を送る処理はありません
- 同じURLでも別端末・別ブラウザではデータは共有されません
- SafariのWebサイトデータを削除するとデータが消える可能性があります

設定画面の「データを書き出す」からJSONバックアップを取れます。

## v3で追加したこと

- 商品追加で画像・スクショを選ぶと、自動で日本語OCRを実行
- OCR結果から次の項目をルールベースで仮入力
  - シリーズ
  - タイトル
  - 価格
  - 受注期間
  - 予約締切
  - 発売日（年月日が明確な場合）
  - 発送予定の原文
  - 全種数
  - 購入上限
  - BOX価格
  - BOX封入数
  - ランダム商品 / 特典ありの推定
- 自動入力された欄は薄紫で表示
- 読み取った生テキストも確認可能
- タイトル未入力でも、画像だけで「検討中」として保存可能

## プライバシーについて

選択した商品画像を、このアプリ独自のサーバーへアップロードする処理はありません。
OCRはブラウザ上の Tesseract.js で実行します。

ただしOCRライブラリと日本語認識用データを読み込むため、初回利用時などに外部CDNへ通信します。
商品画像そのものをOCR APIへ送る方式ではありません。

## OCRについて

これはAIによる商品理解ではなく、画像の文字認識＋ルールベースの項目抽出です。
告知デザイン、文字の小ささ、縦書き、装飾文字などによって誤認識することがあります。
紫色になった自動入力欄だけ軽く確認してから保存する運用を想定しています。
