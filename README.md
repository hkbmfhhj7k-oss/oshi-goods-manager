# 推し活ノート v4 — スクショからAI自動登録

商品追加で商品ページのスクリーンショットを選ぶと、Cloudflare Worker / Workers AI で商品情報を解析して仮入力します。フルページスクショ対応を想定し、メイン商品画像だけを切り出して保存します。

## 使い方
1. 商品追加
2. 商品ページのスクショを選択
3. 自動解析
4. 薄紫の自動入力欄だけ確認
5. 保存

## 解析先
`https://oshi-goods-analyzer.kbwckqs79z.workers.dev`

## プライバシー
選んだ画像は商品情報解析のため Cloudflare Workers AI に送信されます。注文履歴・氏名・住所・電話番号・注文番号・決済情報が写った画像は使わないでください。
